# Zone01 Athens

We are a tuition-free coding school in Athens built around project-driven, peer-to-peer learning.

Our learners develop production skills by building real software, reviewing one another's work, and solving increasingly complex engineering problems. The 24-month program moves from programming foundations through advanced software architecture and a dedicated specialization track.

## What you will find here

- Open resources about our curriculum and specialization tracks
- Software and tools built by the Zone01 Athens team
- Selected community projects and technical experiments
